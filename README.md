# Projeto Banco Virtual (POO)

Bem-vindo ao repositório do Banco Digital! Este projeto é uma aplicação Java que simula as funcionalidades básicas de um banco digital, como criação de contas, depósitos, saques, transferências e consultas de saldo. O objetivo é fornecer uma base sólida para entender como implementar um sistema bancário simples, utilizando conceitos de programação orientada a objetos, manipulação de dados e boas práticas de desenvolvimento.
